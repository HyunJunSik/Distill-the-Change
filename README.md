# ALTER: Transformation-Response Distillation

PyTorch code for combining **ALTER** with existing knowledge distillation objectives.
ALTER matches teacher and student representation responses to image transformations,
including individual representation changes and relative relational changes.
It adds training supervision without adding student inference modules.

## Note

- This release focuses on the CIFAR-100 CNN experiments. Supported distillers are
  **KD, RKD, ReviewKD, InDistill, DKD, MLKD, SKD, and FitNet**.
- The main comparison is an existing distiller using original images versus the
  same distiller combined with ALTER using original and augmented images. Original
  images already receive the common training augmentation.
- Baseline coefficients are unchanged between the paired conditions. With ALTER,
  CE is averaged over original/augmented images, the baseline distillation loss
  uses original images, and response matching uses both images.
- No dataset, pretrained checkpoint, training log, credentials, or machine-specific
  configuration is distributed. Paths are supplied through command-line options.
- The reorganized public entry points have **not been executed or validated**.
  Reported manuscript results below are author-supplied values, not measurements
  generated by running these reorganized entry points. See
  [result provenance](docs/RESULTS_PROVENANCE.md) and [implementation notes](docs/IMPLEMENTATION.md).

Directories for new checkpoints and logs are created automatically under
`CIFAR-100/Utils/runs/` or `ImageNet/Utils/runs/`. Use `--output-root` to change them.

```text

    ├── test
    └── meta
```

Each checkpoint should contain a model state dict directly or under `model`,
`state_dict`, `student`, or `net`. Architecture keys are preserved from the project.
An explicit `--teacher-checkpoint` may be used instead of the checkpoint directory.

## Requirements

Use Python 3.10+ with a mutually compatible CUDA-enabled PyTorch/torchvision pair.
The package pins the project's PyTorch 2.5 / torchvision 0.20 API generation;
install the appropriate CUDA build for your system before installing remaining dependencies.

```bash
pip install -r requirement.txt
```

`requirements.txt` is also supplied for conventional tooling. Dependencies are
PyTorch, torchvision, NumPy and Pillow. No experiment tracking service is required.

## Training

Run commands from this repository's root. Windows PowerShell and Linux use the
same Python commands; quote paths containing spaces.

### CIFAR-100 supervised model training

```bash
python CIFAR-100/Utils/Train.py --data-root ./data --model resnet32x4
```

Add `--download` to explicitly permit downloading CIFAR-100. Otherwise an existing
dataset is required. This training entry point produces a new supervised model;
it does not claim to recreate the supplied teacher header accuracies automatically.

### Baseline distillation

```bash
python CIFAR-100/Utils/Distillation_train.py --data-root ./data --pair resnet32x4_to_resnet8x4 --method KD --teacher-checkpoint ./checkpoints/resnet32x4_ckpt_epoch_240.pth
```

### Baseline + ALTER

```bash
python CIFAR-100/Utils/Distillation_train.py --data-root ./data --pair resnet32x4_to_resnet8x4 --method KD --alter --teacher-checkpoint ./checkpoints/resnet32x4_ckpt_epoch_240.pth
```

To run both conditions from fresh identical student initialization in one command:

```bash
python CIFAR-100/Utils/Distillation_train.py --data-root ./data --pair resnet32x4_to_resnet8x4 --method RKD --compare --teacher-checkpoint ./checkpoints/resnet32x4_ckpt_epoch_240.pth
```

Replace `--method` with any of `KD RKD ReviewKD InDistill DKD MLKD SKD FitNet`.
The corresponding method modules are in `Distiller/`. The common
`DistillationObjective` constructs their baseline losses and optional ALTER.

All eight methods across the eleven CIFAR-100 pairs (176 student conditions):

```bash
python CIFAR-100/Utils/Distillation_train.py --data-root ./data --checkpoint-dir ./checkpoints --all-pairs --methods KD RKD ReviewKD InDistill DKD MLKD SKD FitNet --compare
```

Heterogeneous InDistill additionally prepares one 2x-width student-topology
auxiliary teacher per pair, shared by its baseline and ALTER conditions. These
five preparation runs are additional to the 176 student conditions. Preparation
artifacts are reused when the protocol matches. Both student conditions use the
same intermediate-only warmup; ALTER begins afterward (21 epochs, or 30 for VGG).

Default CIFAR-100 settings: train/validation split 45,000/5,000, separate 10,000
test images, seed 2021, batch 128, SGD LR .01, momentum .9, weight decay .0005,
240 epochs, LR multipliers .1 at 150/180/210. Weak/strong concatenation supplies
90,000 original training samples per epoch. All calculations use FP32.
Checkpoint selection is the fixed final epoch; test accuracy does not select a model.

Weight presets and method adaptations are described in [implementation notes](docs/IMPLEMENTATION.md).
Use `--ce-weight`, `--distill-weight`, `--response-weight`, `--lr`, `--batch-size`,
`--epochs`, `--workers`, and `--output-root` for explicit overrides. They are recorded
with each run. Repeat an interrupted command to resume from the last complete
epoch; complete runs are skipped. Changes to source or protocol require a new output root.
Use separate output roots for concurrent processes; a run directory has one writer.

### ImageNet

Prepare `data/imagenet/train/<class>/` and `data/imagenet/val/<class>/` (or `valid/`).
ImageNet files retain the original ResNet/MobileNet architecture and parameter keys.

```bash
python ImageNet/Utils/baseline_train.py --data-root ./data/imagenet --model resnet18
python ImageNet/Utils/distillation_train.py --data-root ./data/imagenet --teacher resnet34 --student resnet18 --method KD --compare --teacher-checkpoint ./checkpoints/resnet34.pth
```

ImageNet entry points provide a single-GPU reference configuration: 224-pixel
input, 100 epochs, batch 256, LR .1, milestones 30/60/90. They are not presented
as the complete historical Gaudi/distributed/ImageNet experiment pipeline.
This release's InDistill stage-port is CIFAR-100-specific and is not enabled for ImageNet.
No ImageNet results are claimed in this README.

## Test

Evaluate the final student checkpoint without performing training:

```bash
python CIFAR-100/Utils/Test.py --data-root ./data --model resnet8x4 --checkpoint ./CIFAR-100/Utils/runs/resnet32x4_to_resnet8x4/KD_ALTER/student_final.pth
python ImageNet/Utils/test.py --data-root ./data/imagenet --model resnet18 --checkpoint ./ImageNet/Utils/runs/resnet34_to_resnet18/KD_ALTER/student_final.pth
```

Test outputs Top-1, Top-5, CE loss and sample count. Each training condition also
saves `result.json`, `history.json`, `protocol.json`, `feature_layout.json`,
`last.pt` (resume state), and `student_final.pth` (student-only inference state).
